1. 打开你下载的CC Switch软件，你会看到如下图的初始界面

2. 在分组条中，将分组选择至“Codex”
![](https://docs.aircode.run/assets/image/CC-Switch/008.webp)

3. 在供应商分组中，选择如图的“PakcyCode”
![](https://docs.aircode.run/assets/image/CC-Switch/009.webp)

4. 回顾 [创建API令牌](../快速开始/创建 API 令牌.md) ，在 aircode 中创建 **Codex** 分组的令牌，点击复制按钮，复制ApiKey到剪切板
![](https://docs.aircode.run/assets/image/Cli/008.webp)

5. 下拉模态框，找到“API Key”配置项，填入你刚才复制的ApiKey，再点击右下角“添加”按钮
![](https://docs.aircode.run/assets/image/CC-Switch/010.webp)

6. 添加成功后，在主界面会看到我们配置的分组，在右侧点击“启用”按钮，显示“使用中”，则配置完成
![](https://docs.aircode.run/assets/image/CC-Switch/011.webp)

7. 在终端运行 `codex` ，看到对话界面并能正常回复即表示配置完成
![](https://docs.aircode.run/assets/image/Cli/010.webp)
